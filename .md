## Task

Instead of using Stochastic Interploant on the latent sapce of encoder from Pangu (Right now Pangu produces a smoothed conditional-mean latent for t+1, and then decode it). I woudl like to implement the residual approach says: let the SI learn the distribution of what Pangu misses, in latent space, then add it back before decoding.

## Implementation notes

### Prior architecture

- `_encode_det` (`networks/diffusion.py`) runs the frozen deterministic Pangu
  encoder path (`patchembed2d`/`patchembed3d` -> `layer1` -> `downsample` ->
  `layer2` -> `layer3`) on the input (t) fields to produce `x`, Pangu's
  smoothed mean-latent prediction for t+1.
- `StochasticInterpolant.training_step` (`networks/stochastic_interpolant.py`)
  previously interpolated directly from Gaussian noise to `x` itself,
  conditioned on `z` (a small, separately-trained single-channel VAE latent
  of the input surface field). This means the SI was learning to reproduce
  Pangu's own deterministic output from scratch, not a residual/correction
  around it — there was no ground-truth t+1 latent anywhere in the training
  step to regress against.

### Residual approach implemented

- Ground truth: `target_surface_in`/`target_upper_air` (the true t+1 fields,
  already available from the dataloader via `_prepare_inputs_batch` but
  previously unused in the diffusion training call) are passed through the
  same frozen `_encode_det` path (under `torch.no_grad()`) to obtain
  `x_true` — a ground-truth t+1 latent in the identical latent space as `x`.
- Residual target: `residual = x_true - x`, i.e. what Pangu's mean-latent
  encoder misses.
- The SI now interpolates from Gaussian noise to `residual` (instead of to
  `x`), conditioned on `z` as before (UNet conditioning interface left
  unchanged by design — it does not see `x_pangu`, only `z`).
- At sampling time (`prediction`), the SI samples a residual and it is added
  back onto `x` (Pangu's latent) before the shared frozen deterministic
  decoder runs, since that is what the model was trained to predict.

### Files changed

- `v2.0/networks/stochastic_interpolant.py`
  - `training_step`: new required args `target_surface_in`, `target_upper_air`;
    computes `x_true` via frozen `_encode_det` on the ground-truth fields;
    trains on `residual = x_true - x` instead of `x`.
  - `prediction`: adds the sampled residual back onto Pangu's latent `x`
    before decoding.
- `v2.0/train_diffusion.py`
  - `training_one_epoch_diffusion` and `validation_diffusion`: pass
    `target_surface`/`target_upper_air` (already unpacked from
    `_prepare_inputs_batch`) through to `training_step`.

### Known limitations / caveats

- If `params.predict_delta` is ever set to `True`, `target_surface_in` would
  already be delta-normalized rather than a directly comparable t+1 state,
  which would make the residual math incorrect. Currently unused
  (`predict_delta: False` in the relevant configs), but worth guarding if
  that flag is revisited.
- `prediction()`'s final reshape and reuse of `skip` assume `num_samples == 1`;
  this was a pre-existing limitation (not introduced by this change) and was
  left as-is.
- Not execution-verified end-to-end (training is HPC/SLURM-launched via
  `torchrun`, not runnable standalone in this environment) — verified by
  syntax check and manual shape tracing against the existing pipeline.
